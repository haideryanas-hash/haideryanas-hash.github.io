## Built with

- HTML, CSS and vanilla JavaScript in a single `index.html` file
- Glassmorphism using `backdrop-filter`, with a pointer-following highlight effect
- Fully responsive for phones, tablets, laptops and large monitors
- No frameworks or build step
- Hosted free on GitHub Pages
